This Privacy Policy explains how Mysticia Autopilot (the "API Client"), a private tool operated by the owner of the Mysticia YouTube channel, accesses, uses, stores and deletes data. The API Client is used only by the channel owner, on the owner's own computer, for the owner's own channel.

1. Use of YouTube API Services

The API Client uses YouTube API Services. By using it, the user agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy (http://www.google.com/policies/privacy).

1b. Facebook (Meta)

The API Client also publishes the same short videos as Reels on the owner's own Facebook Page using the Facebook Graph API, with the permissions pages_show_list, pages_read_engagement and pages_manage_posts. It only acts on Pages managed by the owner. It does not read or store data about people who follow, comment on or react to the Page. The Page access token is stored only on the owner's computer. See Data Deletion Instructions and Meta's Privacy Policy.

2. Information we access

When the channel owner signs in with Google (OAuth 2.0), the API Client requests these permissions:

  • youtube.upload: to upload the channel's own videos;
  • youtube.readonly: to read the channel's identity and the public statistics of its own videos.

It also reads the public "most popular videos" chart of YouTube. It does not access the user's email, contacts, comments, subscribers' personal data, watch history, or any other Google service.

3. How we use the information

  • To publish the channel's own videos with their title, description and tags.
  • To read view, like and comment counts of the channel's own videos in order to decide which topics to produce next.
  • To use titles of publicly trending videos, in memory only, as a signal of audience interests.

Data is never sold, never used for advertising, and never used to identify or profile individual viewers.

4. Storage

  • The OAuth token is stored only on the owner's computer, in a local file not shared with anyone.
  • Statistics of the channel's own videos are stored in a local database on the owner's computer and are automatically deleted after 30 days.
  • Titles of trending videos from other channels are not stored.
  • No data is stored on any server operated by Mysticia; there is no Mysticia server.

5. Sharing

YouTube API Data is not shared with third parties. Video files and their metadata are sent only to YouTube (Google) and to the owner's Facebook Page (Meta) when publishing. Non-YouTube services used to create videos (text and speech generation, stock image libraries) never receive any YouTube API Data.

6. Cookies

The API Client does not use cookies or similar technologies. This website does not use cookies or analytics.

7. Revoking access and deleting data

  • Access can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions.
  • Once access is revoked, the API Client can no longer access the channel, and the locally stored token and statistics are deleted by the owner within 7 days.
  • To request deletion of any data, write to nbenitezr32@gmail.com. Requests are answered within 7 days.

8. Children

The API Client and the Mysticia channel are not directed at children under 13.
